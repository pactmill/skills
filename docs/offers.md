# Pactmill consulting offers

**ICP:** Platform engineering / DataOps leads; secondary AI platform eng. Mid-to-large orgs with tool sprawl (dbt + DQ + CI + emerging MCP).

**Promise:** Contract-native, agent-ready data products—without ripping out your warehouse.

## 1. Contract & readiness assessment (2–3 weeks)

**Outcome:** Scored inventory of critical data products; ODCS/ODPS gap analysis; Agent Readiness levels; 90-day backlog.

**Includes:** Discovery interviews; scorecard per skill `data-product-readiness-assessment`; executive readout + engineering backlog.

**Success:** Named autonomy ceiling per product; ranked fixes with owners.

## 2. Contract compiler pilot (4–6 weeks)

**Outcome:** One gold curated table under ODCS (+ ODPS); CI breaking gates; compile to expectations / stubs; optional read-only MCP port.

**Includes:** Skills `contract-odcs-review`, `contract-ci-gates`, `mcp-port-policy`; lab-aligned demo in your repo.

**Success:** Breaking schema change fails CI; consumers have a versioned contract; agent tool (if in scope) is policy-annotated.

## 3. AI-assisted DataOps enablement (retainer)

**Outcome:** Team uses coding agents on pipelines/contracts with review gates—not uncontrolled vibe-coding.

**Includes:** Install Pactmill skills; PR checklists; optional golden-trace CI; monthly readiness review.

**Success:** Agents open PRs that pass contract gates; write tools remain blocked until readiness allows.

## How to engage

1. Short discovery call (use discovery prompts in product research interviews).  
2. Pick offer 1 or 2 as beachhead.  
3. Expand to retainer once one product is green.

Pricing is engagement-specific (scope, stack, travel). Contact via GitHub org discussions or email once published on the site.
