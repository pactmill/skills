# Pactmill Skills

Reusable skills and knowhow for **contract-native, agent-ready data products**.

This is the pivotal public repo for Pactmill consulting delivery and AI-assisted DataOps. Product R&D lives in [data-product-factory](https://github.com/pactmill/data-product-factory); runnable demos in [labs](https://github.com/pactmill/labs).

## Positioning

Pactmill helps platform / DataOps / AI teams compile ODCS/ODPS into the tools they already run, and gate agent autonomy with Data Product Agent Readiness.
